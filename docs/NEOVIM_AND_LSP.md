# Droidforge and Neovim

> **Updated:** Droidforge is now a **Neovim distribution** shipped in `nvim/`. The Bun TUI companion is deprecated.

See:

- [KMP_NEOVIM.md](KMP_NEOVIM.md) — install and overview
- [KMP_DEV_FLOWS.md](KMP_DEV_FLOWS.md) — KMP developer workflows
- [MIGRATION_FROM_TUI.md](MIGRATION_FROM_TUI.md) — what happened to the TUI

## Quick install

```bash
ln -sf /path/to/droidforge/nvim ~/.config/nvim
```

`:Forge` opens the main menu for Gradle, run targets, devices, logs, and Kotlin LSP actions.
